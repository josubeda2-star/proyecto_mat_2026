Conceptos fundamentales de la Radicación

📌 Definición

La radicación es la operación inversa de la potenciación. Dado un número b (radicando) y un índice n, la raíz n-ésima de b es el número a tal que aⁿ = b.

Notación: ⁿ√b = a   donde   aⁿ = b
n = índice  |  b = radicando  |  a = raíz (resultado)

🔢 Raíz Cuadrada

Raíz cuadrada (índice 2): √b = a  ⟺  a² = b
Solo existe en ℝ si b ≥ 0. Para enteros negativos no hay raíz cuadrada real.

Ejemplos:

  • √9 = 3  porque  3² = 9
  • √16 = 4  porque  4² = 16
  • √0 = 0  porque  0² = 0
  • √(−4) → no tiene solución real

Cuadrados perfectos: áreas de cuadrados con lado entero

🧊 Raíz Cúbica

Raíz cúbica (índice 3): ³√b = a  ⟺  a³ = b
Existe para cualquier entero, incluso negativos.
  • ³√8 = 2  porque  2³ = 8
  • ³√(−8) = −2  porque  (−2)³ = −8
  • ³√27 = 3  porque  3³ = 27
  • ³√(−27) = −3  porque  (−3)³ = −27

⚖️ Propiedades de la Radicación

Prop. 1 — Producto: ⁿ√(a·b) = ⁿ√a · ⁿ√b   (con a,b ≥ 0 si n es par)
Prop. 2 — Cociente: ⁿ√(a/b) = ⁿ√a / ⁿ√b   (b ≠ 0)
Prop. 3 — Potencia: ⁿ√(aᵐ) = a^(m/n)
Prop. 4 — Raíz de raíz: ᵐ√(ⁿ√a) = ᵐⁿ√a
