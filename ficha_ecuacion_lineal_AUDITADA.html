Conceptos fundamentales

¿Qué es una ecuación?

Una ecuación es una igualdad matemática que contiene al menos una incógnita (generalmente llamada x), cuyo valor se desconoce. El objetivo es encontrar el valor de la incógnita que hace verdadera la igualdad.

Estructura: Miembro izquierdo = Miembro derecho
Ejemplo: x + 3 = 7 → buscamos el valor de x que hace verdadera la igualdad.

La solución o raíz de la ecuación es el valor de la incógnita que verifica la igualdad. En el ejemplo: x = 4.

¿Qué es una identidad?

Una identidad es una igualdad que se cumple para todos los valores de la variable. No importa qué número se coloque en lugar de la variable: la igualdad siempre es verdadera.

Diferencia clave:
• Ecuación: verdadera solo para ciertos valores → x + 3 = 7 (solo para x = 4)
• Identidad: verdadera para todos los valores → x + x = 2x (siempre verdadero)

Tipos de ecuaciones lineales

Tipo 1 — x + a = b
Un paso: despejamos restando a en ambos miembros.
Ejemplo: x + 5 = 9 → x = 9 − 5 → x = 4
Tipo 2 — ax + b = c
Dos pasos: primero restamos b en ambos miembros, luego dividimos por a.
Ejemplo: 2x + 3 = 11 → 2x = 8 → x = 4

Verificación de la solución

Siempre verificar reemplazando el valor hallado en la ecuación original:

Pasos para verificar 2x + 3 = 11 con x = 4:
1. Reemplazar: 2(4) + 3 = 11
2. Operar: 8 + 3 = 11
3. Verificar: 11 = 11 ✓ La solución es correcta.

🎮 Balanza interactiva — Principio de igualdad

La ecuación es como una balanza: lo que le hagas a un plato, tenés que hacérselo también al otro. Si no, ¡se rompe el equilibrio! Empezamos con x + 5 = 8: el círculo azul es la incógnita x, los cuadraditos son unidades.
