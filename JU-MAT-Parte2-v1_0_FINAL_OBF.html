Teoría — Propiedades de la Potenciación

¿Qué es una potencia?

Una potencia es una multiplicación abreviada. Si multiplicamos el número a por sí mismo n veces, escribimos:

aⁿ = a · a · a · … · a (n veces)

Donde a es la base y n es el exponente.

Ejemplo: 2⁴ = 2·2·2·2 = 16

Propiedad 1 — Producto de potencias de igual base

Regla: aᵏ · aⁿ = aᵏ⁺ⁿ  →  Se suman los exponentes y se conserva la base.

Ejemplo paso a paso:

3² · 3⁴ = 3^(2+4) = 3⁶ = 729

¿Por qué? Porque 3²·3⁴ = (3·3)·(3·3·3·3) = 3⁶

Propiedad 2 — Cociente de potencias de igual base

Regla: aᵏ ÷ aⁿ = aᵏ⁻ⁿ  →  Se restan los exponentes y se conserva la base (a ≠ 0).

Ejemplo paso a paso:

5⁷ ÷ 5³ = 5^(7−3) = 5⁴ = 625

¿Por qué? Las 3 veces del denominador "cancelan" 3 del numerador, quedan 4.

Propiedad 3 — Potencia de una potencia

Regla: (aᵏ)ⁿ = aᵏ·ⁿ  →  Se multiplican los exponentes y se conserva la base.

Ejemplo paso a paso:

(2³)⁴ = 2^(3·4) = 2¹² = 4096

¿Por qué? (2³)⁴ significa 2³·2³·2³·2³ = 2^(3+3+3+3) = 2¹²
