T Conceptos fundamentales

¿Qué es una potencia?

Una potencia es una forma de escribir una multiplicación repetida del mismo número.

an = a × a × a × … × a  (n veces)

● La base (a) es el número que se multiplica. Puede ser positivo, negativo o cero.

● El exponente (n) indica cuántas veces se multiplica la base por sí misma.

● Ejemplo: (−3)⁴ = (−3)×(−3)×(−3)×(−3) = 81

Signo de la potencia — base negativa

Cuando la base es negativa, el signo depende del exponente:

(−a)par = POSITIVO  |  (−a)impar = NEGATIVO

● Exponente par → los signos negativos se cancelan de a dos → resultado positivo ✓

● Exponente impar → queda un negativo sin cancelar → resultado negativo ✓

Ejemplo: (−2)⁴ = +16    (−2)⁵ = −32

⚠ Diferencia entre −aⁿ y (−a)ⁿ

¡Son expresiones distintas! El paréntesis cambia todo:

−3² = −(3²) = −9  |  (−3)² = (−3)×(−3) = +9

● Sin paréntesis (−aⁿ): primero se calcula la potencia, luego se aplica el signo negativo.

● Con paréntesis ((−a)ⁿ): el negativo ES parte de la base.

Propiedades esenciales

  • a⁰ = 1 para cualquier a ≠ 0  (ej: 7⁰ = 1, (−5)⁰ = 1)
  • a¹ = a para cualquier a  (ej: 9¹ = 9)
  • aᵐ · aⁿ = aᵐ⁺ⁿ — mismo base: sumar exponentes  (ej: 2³·2⁴ = 2⁷)
  • aᵐ ÷ aⁿ = aᵐ⁻ⁿ — misma base: restar exponentes  (ej: 3⁵÷3² = 3³)
  • (aᵐ)ⁿ = aᵐ·ⁿ — potencia de potencia: multiplicar exponentes  (ej: (2³)² = 2⁶)
  • 10ⁿ tiene exactamente n ceros  (ej: 10⁵ = 100.000)
